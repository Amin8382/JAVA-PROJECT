## Overview

Desktop application for ML-based image defect detection in manufacturing. Uses TensorFlow Java API for inference, generates automated PDF reports via iText, and persists data with MongoDB.

## Features

- **Image Defect Detection**: Deep learning-based classification of product defects
- **Automated PDF Reporting**: Generate detailed inspection reports with iText
- **MongoDB Persistence**: Store inspection results and history
- **Desktop GUI**: Intuitive Java Swing interface

## Tech Stack

| Component | Technology |
|-----------|-----------|
| **Language** | Java |
| **ML Framework** | TensorFlow Java API |
| **Database** | MongoDB |
| **Reporting** | iText PDF |
| **UI** | Java Swing |
